# Language ribbon assets

Python, Java, JavaScript, C++, C, Go, Dart, and TypeScript SVG logos are from
[Devicon v2.16.0](https://github.com/devicons/devicon/tree/v2.16.0/icons).
The accompanying MIT license is included in `DEVICON-LICENSE.txt`.
Brand names and logos belong to their respective owners.

`sql.svg` is a custom generic database symbol for SQL; it does not represent
a specific database vendor.

All icons are served locally, without a runtime CDN dependency.
