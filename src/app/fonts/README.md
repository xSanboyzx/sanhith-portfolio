# Local fonts

Space Grotesk (300–700) is used for headings, body text, and controls.
JetBrains Mono (100–800) is used for small technical labels.
Orbitron (400–900) is used for the Midnight Coder laptop monogram.

Latin variable WOFF2 files are sourced from Fontsource:

- https://fontsource.org/fonts/space-grotesk
- https://fontsource.org/fonts/jetbrains-mono

The Orbitron variable TTF comes from the official Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/orbitron

All three are licensed under the SIL Open Font License; licenses are included here.
Next.js serves the files locally, without third-party font requests at runtime or build time.
